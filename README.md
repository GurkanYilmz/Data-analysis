# Veri Analizi Portfolyosu

Bu depo, veri keşfi (EDA), veri temizleme ve tahmini analiz süreçlerini içeren projelerimi barındırmaktadır. SQL, Python ve Excel kullanılarak gerçekleştirilen uçtan uca veri analizi çalışmalarını içermektedir.

## Projeler

### 1. COVID-19 Veri Keşfi (SQL)

Dünya genelindeki COVID-19 verilerinin SQL kullanılarak analiz edildiği projedir.

* **Dosya:** `COVID Portfolio Project - Data Exploration.sql`
* **Kullanılan Teknikler:** Joins, CTE's, Temp Tables, Windows Functions, Aggregate Functions.
* **Amaç:** Ölüm oranları, aşılama hızları ve ülke bazlı yayılım istatistiklerini sorgulamak.

### 2. Film Endüstrisi Korelasyon Analizi (Python)

Filmlerin bütçeleri, türleri ve hasılatları arasındaki ilişkilerin incelendiği Python projesidir.

* **Dosya:** `Movie Portfolio Project.ipynb`
* **Kütüphaneler:** Pandas, Seaborn, Matplotlib, NumPy.
* **Amaç:** "Yüksek bütçe her zaman yüksek hasılat getirir mi?" sorusuna yanıt aramak ve veriler arasındaki korelasyonu görselleştirmek.

### 3. Nashville Konut Verisi Temizleme (Excel/SQL)

Ham verilerin analiz edilebilir hale getirilmesi için uygulanan veri temizleme sürecidir.

* **Dosya:** `Nashville Housing Data for Data Cleaning.xlsx`
* **İşlemler:** Tarih formatı düzenleme, adres ayrıştırma (Property/Owner Address), mükerrer verilerin (Duplicate) kaldırılması ve kullanılmayan sütunların temizlenmesi.

## Yetkinlikler

* **Veri Analizi:** SQL (PostgreSQL, T-SQL), Python.
* **Görselleştirme:** Matplotlib, Seaborn.
* **Veri İşleme:** Pandas, NumPy, Excel.
